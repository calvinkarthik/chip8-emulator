# CHIP-8 Emulator

A basic CHIP-8 emulator built in JavaScript using the HTML5 Canvas API. Uses Parcel as the bundler for fast development and module support.

## ✅ Features (in progress)

- 🖥️ Pixel-accurate 64x32 canvas display
- 🎮 Keyboard input mapping (WIP)
- 🔊 Audio support with simple beeps (WIP)
- 💾 ROM loading support via `rom/` directory (planned)

## 🚀 Getting Started

### 1. Clone the repo:
```bash
git clone https://github.com/your-username/chip8-emulator.git
cd chip8-emulator
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Start the dev server:
```bash
npm start
```
